# colab-keepalive

Google Colab에서 오래 걸리는 작업을 돌려 둔 채 자리를 비울 때, 브라우저 탭이 유휴 상태로 보여 런타임 연결이 끊기는 것을 줄이는 Windows용 작은 스크립트입니다.

## 하는 일

- 5분마다(±20초) 지정한 Colab 창을 앞으로 가져와 페이지를 살짝 스크롤했다 되돌리고 Shift를 한 번 누른 뒤, 원래 쓰던 창으로 돌아갑니다.
- 셀을 클릭하거나 글자를 입력하지 않으므로 노트북 내용은 바뀌지 않습니다.
- 마우스·키보드 입력이 최근 3분 안에 있었다면(= PC를 쓰는 중) 건너뜁니다.
- 실행 중에는 Windows 절전과 화면 꺼짐을 막습니다.

## 사용법

1. Colab 탭을 브라우저에서 **별도 창으로 떼어** 두고, 그 창에서 Colab 탭이 활성 탭이게 합니다. 창 제목에는 활성 탭 제목만 보이기 때문입니다. 창은 최소화해도 됩니다.
2. `run_keepalive.bat`의 `TITLE`을 노트북 이름 일부로 바꿉니다. `" - Colab"`이면 처음 찾은 Colab 창을 씁니다.
3. `run_keepalive.bat`을 더블클릭합니다. 처음 실행할 때 `pyautogui`가 없으면 설치합니다.

먼저 확인만 하려면 `run_keepalive.bat --dry-run`으로 실행합니다. 창을 찾았는지만 출력하고 아무것도 조작하지 않습니다.

실제로 움직이는 모습을 보려면 `run_keepalive_test.bat`을 실행합니다. 입력이 5초 동안 없으면 동작하고, 그 뒤로는 10초마다 반복합니다. 확인했으면 Ctrl+Alt+Q로 끄고 `run_keepalive.bat`을 실행하세요.

## 끄기

- **Ctrl+Alt+Q**: 어느 창에서 눌러도 됩니다.
- 콘솔 창에서 **Ctrl+C**
- 마우스를 **화면 왼쪽 위 구석**으로 옮깁니다(pyautogui 비상 정지).

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--title` | ` - Colab` | 대상 창 제목에 들어간 문자열 |
| `--every-min` | 5 | 신호 간격(분) |
| `--idle-min` | 3 | 이 시간 이상 입력이 없을 때만 조작 |
| `--every-sec`, `--idle-sec` | | 위 두 옵션을 초 단위로 지정(테스트용) |
| `--dry-run` | | 창 찾기만 하고 조작하지 않음 |

## 주의

- 브라우저의 탭 절전 기능(Chrome 메모리 절약, Edge 탭 절전) 예외에 `colab.research.google.com`을 추가해야 탭이 잠들지 않습니다.
- 화면이 잠기면 조작할 수 없습니다. 실행 중에는 화면 꺼짐을 막지만, 회사 정책 등으로 강제 잠금이 걸려 있으면 동작하지 않습니다.
- 자동 입력으로 세션을 유지하는 것이 Colab 이용 정책에 맞는지는 각자 확인하세요. 오래 백그라운드로 실행해야 한다면 Colab Pro+의 백그라운드 실행이 공식적인 방법입니다.
- 런타임 연결이 끊겨도 이어서 실행할 수 있게 작업 코드를 짜 두는 것이 가장 확실한 대비입니다.
